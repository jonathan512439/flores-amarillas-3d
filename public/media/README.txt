Coloca aquí de 1 a 5 fotografías (photo-01.jpg ... photo-05.jpg) y una canción.
Después edita manifest.json:
- name: nombre de ella
- photos: conserva hasta 5 objetos con src y name
- audio: ruta relativa, por ejemplo media/cancion.mp3
- phrases: lista de frases de amor
- dedication: dedicatoria que aparece bajo el título

El navegador no enumera carpetas automáticamente: incluye cada foto en manifest.json.
Para instrucciones completas, consulta README.md en la raíz del proyecto.
